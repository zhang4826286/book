# 个人读书书架

> 一个让每本书都有归处的私人阅读空间

**版本** v1.2 | **产品** 个人阅读管理工具

---

## 项目简介

个人读书书架是一款面向个人读者的阅读管理工具，不依赖特定阅读平台，不强调社交分享，专注于帮读者把书籍管起来、把进度跟住、把笔记留住。

## 核心模块

| 模块 | 功能 |
| --- | --- |
| 书籍管理 | 手动录入 / ISBN 检索 / 批量导入 / 封面上传 / 重复检测 |
| 书架视图 | 书架/网格/列表三种模式 / 4 种主题 / 拖拽排序 / 悬停预览 |
| 阅读进度追踪 | 状态切换 / 进度条 / 阅读计时器 / 阅读目标 / 打卡提醒 |
| 阅读统计 | 热力图 / 月度趋势 / 分类分布 / 年度回顾 / 报告导出 |
| 读书笔记与书评 | 五星评分 / 书评 / 摘录笔记 / 标签系统 / 跨书搜索 / 模板 |
| AI 语音阅读助手 | 语音对话 / 智能朗读 / 4 种语音人格 / 上下文感知 / 存为笔记 |
